Repository ini dibuat untuk mempersiapkan keikutsertaan dalam ajang **National Artificial Intelligence Summit & Competition (NAISC) 2026** (Kategori: **AI Web Applications**), dengan mengusung proyek **Smart Face Recognition Attendance System** (Aplikasi Absensi Digital Berbasis Pengenalan Wajah).

## Tema Kegiatan
> *"Akselerasi Inovasi Kecerdasan Buatan: Mengukur Solusi Digital Menuju Kemandirian Teknologi Bangsa"*

## Poin-Poin Penting

### Kategori Lomba yang Diikuti
- **AI Web Applications**: Pengembangan platform/aplikasi web cerdas yang mengintegrasikan model *machine learning*, *computer vision*, atau agen AI interaktif[cite: 4]. Proyek ini memanfaatkan *Computer Vision* (OpenCV) yang dibungkus dengan antarmuka web interaktif untuk sistem absensi digital.

### Kriteria Peserta
- Pelajar SMA/SMK/MA sederajat di seluruh Indonesia.
- Berupa individu atau tim dengan anggota maksimal 3 orang (termasuk 1 ketua).

### Informasi Tambahan
- **Biaya Pendaftaran**: Rp 50.000 / Tim *(Gratis bagi sekolah yang menerima surat undangan resmi delegasi)*.
